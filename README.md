# dacapo-learning-coordinator

交互式概念网络学习。每篇文章同步输出概念卡，追踪掌握度，构建概念网络，根据反馈自适应调整。用户要求系统学习概念密集型课题、需要长期记忆或想建立知识网络时使用。

## 安装

```bash
npx -y skills add hou-152/dacapo-learning-coordinator -g --all
```

## 使用

安装后，可以这样开始：

> 使用 $dacapo-learning-coordinator 完成它所解决的任务。

## 运行依赖

- 支持 Agent Skills 的客户端
